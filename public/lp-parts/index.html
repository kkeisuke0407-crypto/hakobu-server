体験談ランキング型LP パーツ集

「◯◯はやばい？使った感想＆実際に◯◯できた5選」型の記事LPを組むための部品です。参考サイトの見せ方の型だけを抜き出して作り直しました（文章・画像・サービス名は使っていません）。

全46パーツ。CSSは parts.css 1ファイル。LPで使うときは parts.css を読み込み、本文を class="mt-body" で囲む。

  • 基本の流れ
  • 画像の入れ方
  • A. 見出し
  • B. 本文と強調
  • C. 比較・結論
  • D. 口コミ・体験談
  • E. ランキングの中身
  • F. ボタン（CTA）

  • H. 枠まわり

基本の流れとルール

流れタイトル → アイキャッチ → 悩みの問いかけ → 共感（私も同じだった）→ 答えの予告（黄マーカー）［この3つは「導入の会話」1つに置き換えてもよい］→ PR・年齢注記 → 比較表 → 結論ボックス → 比較相手の口コミ（良い・悪い）→ 自分の体験（目的で選ぶ）→ ランキング（各順位：見出し・バナー・実体験・特徴リスト・ボタン）→ 1位だけ深掘り（コツ・会話例・体験談・登録手順）→ まとめ → 全順位のボタン → 関連記事
色青＝見出し・ボタン／赤＝強調・注意／黄マーカー＝結論
口調1人称の体験談。語りかけ（「〜ですよね」「w」は1記事で数回まで）。1段落1〜2文、改行多め
ボタン大ボタンの上に「＼ひとこと／」、下に注記。ひとことは毎回変える。大ボタンの合間にテキストリンクのボタン
必ず入れる冒頭のPR表記・年齢制限の注記・口コミや体験談の「※個人の感想です」。体験していないことは書かない

画像の入れ方（台本からLPを作るとき）

手順台本を受け取る → パーツで本文を組む → スマホ幅で画像のない区間を測る → 置き場所を決め、そこに「画像指示枠」（I章）を入れる → 既存素材を先に割り当て、足りない所だけ新規生成のプロンプトを書く → 画像ができたら「本文画像」に差し替える
配置スマホ1画面（約800px）に画像・会話・表・CTAのどれか1つ以上。文章だけの区間は最大1.5画面。H2の直下は扉の画像（H2と同じ見出しを画像に入れない）。画像が先、文章が後
役割扉（写真）／説明図（図解）／感情（表情アイコン・挿絵）／証拠（数字・実例）／行動（手順・登録）。同じ役割を3連続にしない。前半＝共感 → 中盤＝理解 → 後半＝行動
作り方図解も含めて全部、画像生成AIで作る「画像」にする。HTMLやSVGで図を自作しない。既存素材があれば先に使う。推すサービスの紹介の扉は広告主バナー（ASP素材を改変しない・計測リンク・PR表記）
画像内の文字台本（本文）からそのまま。足さない・言い換えない。生成後に1字ずつ照合し、誤字・余計な文字は再生成
テイスト1本のLPの図解は同じテイストにそろえる。既にある図解を参照画像として一緒に渡す
人物・ロゴASPの画像制約（人物NGなど）を先に確認。分からなければ人物なしで設計。ロゴ・認証マークは許可なく使わない。写真風の人物には「※写真はイメージです」
公開前画像指示枠（mt-imgslot）が1つも残っていない／全画像に alt・width・height／表示されない画像がない／375pxで横スクロールなし

I. 画像

LPを作るときは、画像を入れる場所すべてに「画像指示枠」を置く。画像ができたら「本文画像」に差し替える。置き方のルールはページ上の「画像の入れ方」。

画像指示枠（LP作成中に置く）mt-imgslot / --have / --ad
使う場面
台本からLPを組むとき、画像を入れる場所すべて。画像を作る人（ユーザー）への指示書を兼ねる。
ルール
1枠＝1枚。見出しに ID・種類・役割・形。種類で色が変わる（紫＝新規生成、青＝既存素材、橙＝広告主バナー）。中身は「何を見せるか」「置き場所」「画像内の文字（本文からそのまま）」「alt」「生成プロンプト」。新規生成はプロンプト必須。図解の共通スタイル（色・カード・文字・人物の有無）は、LPで最初の新規生成の枠のプロンプトの先頭に全文を書き、2枚目以降は「（このLPの図解の共通スタイル）」で参照する。
NG
公開ページに枠を残す／画像内の文字を本文と変える／図をHTMLやSVGで自作して済ませる

本文画像（差し替え後）mt-img
使う場面
画像指示枠の画像ができたら、この形に置き換える（広告主バナーは mt-banner）。
ルール
全幅。alt・width・height を必ず入れる。FV以外は loading="lazy"。写真・人物・写真風のAI画像は下に「※写真はイメージです」。
NG
altを空にする／小さい画像を浮かせる
